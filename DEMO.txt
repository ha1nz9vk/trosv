TROSV - HƯỚNG DẪN CHẠY DEMO (CHỈ ĐỂ DEMO, KHÔNG PHẢI PRODUCTION)
=================================================================

Yêu cầu: một máy Debian có Docker hoặc Podman. Không cần cài PHP/Node
trực tiếp, tất cả chạy trong container.

CÁC BƯỚC
--------
1) Lấy mã nguồn:

     git clone https://github.com/52400067/trosv.git
     cd trosv

2) Tạo file .env từ mẫu (copy nguyên, không cần sửa gì cho localhost):

     cp .env.example .env

   Tạo APP_KEY và ghi vào .env (chạy 2 lệnh này):

     echo "APP_KEY=$(docker run --rm php:8.3-cli php -r 'echo "base64:".base64_encode(random_bytes(32));')" >> .env
     echo "SEED_ON_BOOT=1" >> .env    # tự động nạp dữ liệu demo khi boot

3) Bật toàn bộ hệ thống (lần đầu mất vài phút để build):

     docker compose up -d --build

   Nếu dùng Podman thì lệnh tương tự: podman compose up -d --build

4) Đợi khoảng 1 phút cho các service healthy, rồi mở web:

     Web : http://localhost:5174
     API : http://localhost:5174/api   (same-origin qua nginx)

   Máy khác trong cùng LAN có thể vào bằng http://<IP-máy-chạy>:5174

DỪNG HỆ THỐNG
-------------
     docker compose down          # dừng, giữ dữ liệu
     docker compose down -v       # dừng và xóa sạch dữ liệu

LƯU Ý
-----
- Đây CHỈ là cấu hình demo trên máy cá nhân. Không dùng cho production:
  mặc định là HTTP, mật khẩu DB đơn giản, dữ liệu mẫu được seed sẵn.
- Muốn chạy lại seed cho sạch: docker compose exec backend php artisan migrate:fresh --seed --force
- Chi tiết đầy đủ (deploy thật, backup, restore): xem README.md và docs/DEPLOY.md
